# Privacy Policy – Tilt social

**Last updated: 18 November 2026**

## 1. Introduction

Tilt social is an application designed to help its account owner discover and review relevant public posts on Threads and prepare suggested replies.

This Privacy Policy explains how information is collected, processed, stored and shared when the application is used.

## 3. Information We Process

Depending on the permissions granted by Meta, the application may process publicly available Threads post information, including:

- Public post text;
- Public username;
- Post ID;
- Post URL;
- Publication timestamp;
- Other fields made available through the authorised Threads API.

The application also processes the account owner's approval decisions and information necessary to manage the application's operation.

## 4. Purposes of Processing

Information is processed exclusively to:

- Search for relevant public Threads posts;
- Identify posts written in European Portuguese;
- Analyse post relevance and quality;
- Generate suggested replies;
- Translate posts and suggested replies into English for review;
- Send proposals to the account owner through Telegram;
- Publish replies only after the account owner's explicit approval.

The application does not intentionally publish replies without the account owner's approval.

## 5. Third-Party Service Providers

The application uses the following service providers:

**Meta Platforms:** Provides the Threads API and access to authorised Threads data.

**GitHub:** Hosts the application source code, runs automated workflows through GitHub Actions and stores the application's database.

**OpenAI:** Processes post text to analyse relevance, generate suggested replies and provide English translations.

**Telegram:** Delivers post information, translations and suggested replies to the account owner for review and approval.

These providers process information as necessary to provide their respective services, subject to their own terms and privacy policies.

## 6. Data Storage and Security

Application data is stored in the application's database hosted in the GitHub repository.

Access tokens and API credentials are stored using GitHub repository secrets and are not intentionally included in the application's source code.

Reasonable technical and organisational measures are used to protect information against unauthorised access, disclosure or alteration.

## 7. Data Retention

Information is retained only for as long as necessary to operate the application, maintain approval records and fulfil the purposes described in this policy.

Information that is no longer required should be deleted securely.

## 8. Data Sharing

The application does not sell personal data.

Information is shared only with the service providers described in this policy to operate the application and deliver its functionality, or where disclosure is required by applicable law.
